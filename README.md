# my-quanternet
Live companion to the book “Building the Quanternet”

## Modules

### The Breathing Universe
Interactive 3D visualization portal for Arnon Daniel Katz's “Breathing Universe” cosmology theory. Built with Three.js, WebGL 2.0, Web Audio API, and custom GLSL shaders.

See [`breathing-universe/`](breathing-universe/) for the full source and documentation.
